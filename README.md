# 三小只的影像手帐 · MedSeg Studio

医学影像分割与定量测量的浏览器教学工作台。导入的影像在浏览器本地处理。内置脑部 MRI、胸部 CT 和皮肤镜三种教学样本。

点击样本卡切换影像，在观察窗内设置种子或用画笔精修。报告支持复制和下载 TXT，分割叠加图和二值掩膜可导出 PNG。

与参考轮廓对比时，除 Dice、IoU、Recall、Precision 外，还会计算 HD95（95% 豪斯多夫距离）和 ASSD（平均对称表面距离），并按 Dice 给出质量评级；最大长径会标注是否达到 RECIST 1.1 的 10 mm 可测量阈值。「测量手帐」可以把不同样本、不同算法的结果记下来横向比较，并导出 CSV（记录保存在浏览器本地）。

键盘快捷键：`1`–`4` 切换算法，`Z` / `Ctrl+Z` 撤销，`[` `]` 调整画笔半径，`E` 切换增补/擦除，`M` 记一笔，`R` 打开报告。点击页面会出现一只小蓝鲸，右上角可以关闭动效。首次打开时默认跟随系统的减少动态效果偏好。

## 本地预览

在仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。网页用相对路径加载本地素材，可直接由 GitHub Pages 静态托管。

## 文件

- `index.html`、`journal.css` 包含页面结构、基础样式与响应式布局。
- `kawaii.css` 是糖果色主题层：对话气泡、糖果按钮、彩色卡片与滑块样式。
- `segmentation.js` 包含 Canvas 渲染、分割算法、量化报告和导出。
- `postcard.js`、`stickers.js` 处理明信片对话、精灵提示和点击反馈。
- `assets/` 包含教学图像、角色插画、字体子集及第三方库许可文本。

本项目供医学影像教学与算法演示。角色插画依据用户提供的参考形象绘制。
